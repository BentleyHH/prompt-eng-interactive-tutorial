# ATMEN — Werkzeugkasten

Kanonische Markendateien fuer Helgoland — ATMEN.

- **logo/** Atemlinie & Wortmarke als Vektor (SVG, echte Pfade) + PNG-Exporte
- **farben/** Farbwerte als CSS, JSON und Klartext (HEX/RGB/CMYK-Richtwert)
- **schriften/** Alle drei Markenschriften als WOFF2 inkl. OFL-Lizenzen

Regeln, Groessen und Schutzraum: siehe CI-Guidelines (ci-guidelines.html / ATMEN-CI-Guidelines.pdf).
Es gibt genau EINE Atemlinie. Keine eigenen Wellen zeichnen.
